# Native examples

`examples/` contains realistic but project-specific objectives such as GTOP,
Mazda, trading, jobshop, multi-UAV assignment, and Buckingham–Pi analysis.

| Directory | Role |
|---|---|
| [`../foundations/`](../foundations/) | standard academic suites, Lennard-Jones scaling, indicators, and seven compact lessons |
| `examples/` | realistic native objective implementations and executable examples |
| [`../tutorials/`](../tutorials/) | 22 complete simulator-in-the-loop experiment protocols |

See the [example guide](../docs/examples.md) for binaries, data, and commands.
